1. 修复长截图无法识别文字的问题：长图按带重叠的分块逐段识别，保留整图与逐字坐标；分块交界处去重，较长任务使用相应的等待时间，避免整图缩小后文字丢失。
2. 文字识别后在右上角显示搜索框，支持中英文关键词、匹配计数、上一处 / 下一处与结果高亮。长图会自动滚动到匹配位置，历史图片编辑器同样支持；搜索与文字选择不影响导出的图片。
3. 长截图支持向上、向下双向拼接。从页面中间开始，可向上补齐顶部，再向下继续；反复经过已采集区域不会重复添加内容。
4. 优化长截图文字识别：按 CPU 数量最多两路独立实例并行处理分块，修正窄分块被无谓放大的检测配置，保留原图坐标与阅读顺序。
5. 修复已识别文字无法搜索的问题：兼容 OCR 空格、零宽字符、全角字符及同一行的拆分文字块，补齐缺失字符坐标的定位；搜索不修改复制内容。

### 使用方式

- 完整解压 **ShotInk-portable.zip**，运行其中的 `ShotInk.exe`，保留同目录的 `ocr` 文件夹。
- 长截图完成后点击「文字识别」，即可选择复制文字，并使用右上角搜索框查找全文。
- `Ctrl+F` 聚焦或重新打开搜索，`Enter` / `F3` 查找下一处，`Shift+Enter` / `Shift+F3` 查找上一处；搜索框内按 `Esc` 关闭搜索并保留识别结果。
- 滚动时保持相邻画面有重叠，避免拖动滚动条大跨度跳转；固定导航、动画和动态内容可能影响拼接。
- 支持 Windows 10 / 11 x64，需要 .NET Framework 4.8 和 Visual C++ x64 运行库。更新前请从托盘退出旧版。
