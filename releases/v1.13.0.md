# ShotInk 1.13.0

- GIF 工具右侧新增录屏入口，点击后重新框选录制区域。
- 选框下方新增麦克风、系统声音和鼠标指针开关，首次使用显示气泡引导，后续记住设置。
- 开始录屏前显示 3 秒倒计时。录制导航显示计时、暂停、继续和结束，支持拖动导航，每段最多 1 分钟。
- 结束后进入录屏编辑器，支持选段播放、删除选中时间段、删除当前帧、撤销和重做，剪辑同步处理音频。
- 标注支持当前帧、选中时间段或全部内容，提供形状、线条、画笔、荧光笔、马赛克、文字与橡皮擦。
- 支持将编辑后的选段保存为 MP4 或复制到剪贴板，便携包自带录屏所需组件。

- 录屏功能条沿用圆角图标风格，默认位于选框下方，支持拖动。倒计时仅保留圆形背景，透明度为 60%。
- 短滑块展开后拖动点保持在鼠标位置，靠近窗口边缘时继续保留当前数值，并优化圆角边缘绘制。

提供完整 OCR 版 ShotInk-portable.zip 与轻量版 ShotInk-portable-lite.zip。
