# ShotInk 1.10.0

- 新增快速截图：Ctrl+Alt+Q 按上次坐标和尺寸截图后直接复制并结束；Ctrl+Alt+E 截图后直接编辑。记忆区域支持重启恢复。
- 新增全屏截图快捷键 Ctrl+Alt+A，截取所有显示器并进入编辑。
- 区域截图自动识别窗口边界，单击直接编辑；长按 350 毫秒或拖动改为手动框选，保留原有标注、选区调整与取消操作。
- 剪贴板没有图片时，F3 自动使用截图历史的第一张图片贴图。
- 设置和托盘菜单提供全部新快捷入口；新增快捷键支持修改、清除、冲突检测与恢复默认。

提供完整 OCR 版 ShotInk-portable.zip 与轻量版 ShotInk-portable-lite.zip。

- 修复确认更新被贴图或编辑窗口阻止的问题：确认后自动结束截图、关闭相关窗口并继续更新；未保存标注沿用保存确认，取消或失败时明确显示原因。
- 更新成功或失败后自动清理安装 ZIP 和解压暂存文件，保留回滚备份与错误日志。
- 更新详情改为不可编辑、不可选中的文字展示，点击下载不再出现文字选中效果。
- 快速截图并复制成功后显示短暂成功提示，不抢焦点、不弹出编辑框。
