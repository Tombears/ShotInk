1. 马赛克改为灰度像素块，画笔和选框模式均保留独立颗粒大小、笔刷大小及撤销、重做。
2. 历史记录默认保留 10 张，在工作台「保留历史」旁直接修改保留张数，重启后保留设置；只清理历史记录目录，不影响手动保存的图片。
3. 长截图整合到截图选区：在文字识别旁新增长截图图标，直接使用当前选框作为采集范围；原长截图快捷键继续作为快捷入口。
4. 默认手动滚动，以 10ms 为目标间隔检测画面变化，并在后台异步拼接。采集时工具栏仅显示「完成」，点击后恢复全部工具。
5. 长图始终在固定选框内预览，通过滚轮和滚动条上下浏览，并可继续标注、选字和导出整张长图。
6. 高度达到 30,000 像素或总像素达到 8,000 万时自动完成；检测与拼接使用有界待处理队列，取消后释放后台任务与图片资源。

### 长截图修复

- 修复点击长截图后滚轮没有作用于原页面的问题，鼠标停留在完成按钮附近也能继续滚动。
- 连续滚轮输入按截图进度依次执行，保留采集到的中间画面，改善快速滚动时漏掉内容的问题。
- 加快重叠区域匹配，改善文字页面和较小重叠区域的拼接；页面跳转导致无法继续拼接时，保留已完成部分并显示提示。

### 下载与运行

- 下载 **ShotInk-portable.zip**，完整解压后运行其中的 `ShotInk.exe`，保留同目录的 `ocr` 文件夹。
- 支持 Windows 10 / 11 x64，需要系统已有 .NET Framework 4.8 和 Visual C++ x64 运行库。
- 升级前请先从系统托盘退出旧版 ShotInk。
