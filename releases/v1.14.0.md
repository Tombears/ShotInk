# ShotInk 1.14.0

- 新增外观设置，提供极简线性、双色扁平、柔和立体、磨砂玻璃、暗色霓虹、复古像素、黑白水墨七套皮肤及经典选项。
- 支持实时预览，保存后自动记忆，取消或关闭设置恢复此前外观。
- 工具栏及功能图标随皮肤统一切换，按钮、滑块和截图复制完成提示提供对应风格的互动反馈。
- 两个版本均支持换肤，轻量版沿用自身的功能入口。
- 修复靠近屏幕底部及多屏场景下开始录屏工具栏超出可见区域的问题。
- 录屏设置新增麦克风设备选择和 100%～400% 软件增益，增强轻声音量、限制混音峰值，并反馈静音或无声音状态。
- 合并 OCR 托管组件以减少解压文件数量，内置更新采用并行解压与同步哈希校验。
- 完成更新或成功回滚后自动清理临时备份。
- 按七套确认稿接入原始图标素材，换色按钮使用环形调色盘；图标与界面采用四倍分辨率绘制后缩小，清理透明边缘并改善黑边、毛边。
