1. 截图工具栏缩小按钮间距和外侧留白，压缩参数面板的行高、标签间距与底部空白，统一圆角外观；拖动左侧点阵握柄可移动工具栏，切换绘图工具后保留位置。
2. 长截图按钮后新增 GIF 录制入口，使用当前截图选框录制，点击「停止录制」进入剪辑；Esc 可取消。
3. GIF 剪辑支持播放所选区段，在同一条时间轴上拖动起点、终点双滑块裁剪，高亮显示保留区段。预览区按 ← / → 逐帧查看；选中起点或终点滑块后，按 ← / → 每次调整一帧。
4. 支持复制动画 GIF 文件和保存 GIF，保存沿用图片的默认目录与「每次保存时询问保存位置」设置。

5. 提升工具栏圆角、颜色圆点、按钮图标及滑块的边缘显示质量，使用超采样和透明过渡改善锯齿；移除 GIF 剪辑底部的重复拖动提示和对应空白。

### 使用方式

- 完整解压 **ShotInk-portable.zip**，保留 `ocr` 文件夹，退出旧程序后运行新版。
- 框选录制区域，点击长截图右侧的播放方框图标。录制目标是原始屏幕内容，不包含截图标注。
- 默认约 10 帧/秒；受画面大小和编码耗时影响，实际采样间隔会变化，导出保留实际时长。单次最多 60 秒，压缩帧缓存达到 192 MiB 时也会停止并进入剪辑。
- 点击「复制 GIF」或按 Ctrl+C，可粘贴到支持动图文件的应用；目标应用是否播放动画取决于其 GIF 文件粘贴支持。也可按 Ctrl+S 保存后发送文件。
- 支持 Windows 10 / 11 x64，需要 .NET Framework 4.8 和 Visual C++ x64 运行库。
