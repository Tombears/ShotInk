1. 新增 Gitee 版本检查：程序启动后检查一次，之后每小时自动检查，也可点击「检查更新」立即重新检测。
2. 检测结果只在设置中显示，不自动弹窗或显示托盘气泡；发现新版本时启用「下载更新」。
3. 点击「下载更新」直接通过默认浏览器打开 Gitee 便携包链接，由用户手动下载、解压和更新。
4. 同版本修复包也能检测；已安装相同构建时不重复提示，不提示降级安装旧版本。设置中可关闭自动检查，仍可手动检测。

### 使用方式

- 在设置中点击「检查更新」，发现更新后点击「下载更新」。
- 浏览器下载 **ShotInk-portable.zip** 后，从系统托盘退出 ShotInk，将便携包完整解压覆盖到原程序目录，再运行 ShotInk.exe。
- 保留便携包内的 OCR 组件和 ShotInk.build.sha256。设置位于当前 Windows 用户的数据目录，更新后继续使用已有默认保存目录、快捷键和截图历史。
- 更新检测和下载链接均使用 Gitee，无需提供账号或令牌。
