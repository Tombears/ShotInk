1. 优化文字识别选中效果：识别完成后直接全选，同一行使用连续荧光高亮，连接文字和词间空隙，不再显示一格格的字符选框；表格相隔较远的列仍分别高亮。
2. 各工具独立记住颜色和线宽，文字字号、马赛克颗粒和画笔大小、橡皮擦大小分别保存，切换工具、打开新截图与重启后继续保留。
3. 优化截图选区的移动与缩放：拖动期间统一绘制选区和标注预览，松手后更新画布，减少旧边框、手柄与窗口移动留下的残影。
4. 工作台和托盘菜单新增「设置」，支持修改区域截图、剪贴板贴图、滚动长截图的全局快捷键；快捷键冲突时提示并保留原设置。
5. 支持选择图片默认保存文件夹和设置每次是否询问保存位置；关闭询问后，普通截图、历史图片及长图编辑器的保存按钮和 Ctrl+S 均直接保存到指定文件夹。
6. 保留已有截图历史和偏好；历史记录与手动保存目录独立，保留最近 100 张历史时不会清理手动保存的图片。

### 下载与运行

- **ShotInk-Setup.exe**：完整离线安装包，按提示安装或升级即可使用。
- **ShotInk-portable.zip**：完整解压后运行其中的 `ShotInk.exe`，保留同目录的 `ocr` 文件夹；需要系统已有 .NET Framework 4.8 和 Visual C++ x64 运行库。
- 支持 Windows 10 / 11 x64；升级前请先从系统托盘退出正在运行的 ShotInk。
