1. 修复长截图框移动时的残影：拖动期间统一绘制图片、标注和滚动条预览，松手后恢复编辑控件，原位置及时擦除。
2. 马赛克按原图颜色生成均值像素块，自适应背景明暗，保留蓝色等彩色内容；修复不同缩放比例下方块间的白色细缝。
3. 马赛克新增「高斯模糊」，可单独设置模糊强度；像素块和模糊均支持画笔与选框，继续保留独立画笔大小、撤销和重做。
4. 选框马赛克显示虚线编辑框，支持拖动、缩放和继续调整效果，移动、缩放与效果修改可分别撤销；编辑框不进入导出图片。
5. 折线操作整合进「直线」与「箭头」：第一次单击确定起点，后续单击添加折点，右键、双击或 Enter 完成；两点画直线，多点画折线，箭头仅在最后一段末端显示。Backspace 退回一个节点，Esc 取消当前线条；整条线作为一次操作撤销和重做。
6. 图标采用彩色四角截图框与黄色钢笔的最终稿，统一应用程序文件、工作台、编辑窗口与托盘图标，包含适用于 Windows 的多种尺寸。
7. 启动时刷新程序文件的图标缓存，避免覆盖更新后资源管理器仍显示旧图标。
8. 修复右键取消截图时触发后台窗口右键菜单的问题；普通截图和长图预览均在松开右键后关闭，线条绘制中的右键仍用于完成当前线条。
9. 重新设计截图工具栏图标，统一线宽与留白；文字识别使用扫描四角与「文」，长截图使用向下滚动箭头，马赛克使用像素块，画笔与荧光笔更容易区分。
10. 重新设计各工具展开后的设置面板，按模式、颜色和参数分组，提供圆角色块、独立数值显示及细 / 中 / 粗线宽预设；形状、线条、画笔、荧光笔、马赛克、文字、橡皮擦与文字识别分别使用不同选中色，图标、选项和滑条保持一致。

11. 设置新增「开机启动」，默认关闭。开启并保存后，登录 Windows 时自动启动并驻留托盘；取消勾选并保存即可关闭。双击托盘图标可打开工作台；移动程序文件夹后，请重新保存设置以更新启动路径。

12. 优化按 F1 后准备截图与拉选框的流畅度，减少快速移动、缩小和反向拉框时的卡顿；及时清除旧十字线、尺寸提示与选区边框，改善残影。

13. 提升长截图滚轮响应速度，上一帧处理完成后及时继续滚动；改变方向时清除待执行的旧方向滚动。修复向上回看、再次向下经过已采集区域时重复拼接的问题，只在超过原末尾后追加新内容。

### 下载与运行

- 下载 **ShotInk-portable.zip**，完整解压后运行其中的 `ShotInk.exe`，保留同目录的 `ocr` 文件夹。
- 支持 Windows 10 / 11 x64，需要系统已有 .NET Framework 4.8 和 Visual C++ x64 运行库。
- 更新前请先从系统托盘退出旧版 ShotInk。
