1. 文字标注改为直接在图片上输入，支持中文、多行、独立字号、颜色、粗体和斜体；普通截图、长截图和历史图片使用相同操作。
2. 文字框支持拖动边框移动、拖动四角等比缩放、拖动顶部圆点旋转，按住 Shift 可按 15° 对齐；双击或 F2 可继续编辑已有文字。
3. 字号和颜色实时应用到当前文字，输入时 Enter 换行、Ctrl+Enter 完成、Esc 取消本次编辑，Ctrl+C 复制输入框中的文字。
4. 文字修改、移动、缩放、旋转和样式调整支持撤销、重做；保存、复制和贴图仅输出文字，不包含编辑边框或手柄。
5. 修复文字编辑时的白底和双层边框，编辑中保持图片背景可见；文字框随输入、删除和换行紧凑调整。
6. 修复输入位置偏移，中文组合文字和候选窗口跟随图片上的输入光标，输入过程不再反复重建字体。

### 下载与运行

- **ShotInk-Setup.exe**：完整离线安装包，按提示安装或升级即可使用，保留已有截图历史和设置。
- **ShotInk-portable.zip**：完整解压后运行其中的 `ShotInk.exe`，保留同目录的 `ocr` 文件夹；需要系统已有 .NET Framework 4.8 和 Visual C++ x64 运行库。
- 支持 Windows 10 / 11 x64；升级前请先从系统托盘退出正在运行的 ShotInk。
