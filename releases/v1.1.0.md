1. 新增本地 OCR：点击橡皮擦右侧的「方框＋文」按钮，直接在图片上拖选并复制文字，支持中英文、数字和标点。
2. 支持跨行选择表格某一列、单击选择英文词、双击选择整行，以及 Ctrl+A 全选、Ctrl+C 复制；选字高亮不会进入导出图片。
3. 集成 RapidOcrNet / ONNX Runtime，使用 PP-OCRv6 small 模型；通过预加载、模型会话复用和相同图片缓存减少等待，截图不上传服务器。
4. 马赛克和橡皮擦的滑条手柄改为带高光、渐变和阴影的椭圆形，支持鼠标拖动、点击轨道、方向键和滚轮调节。
5. 优化区域橡皮擦的重叠涂抹，按实际画笔或选框范围恢复原图；继续支持撤销和重做。
6. 修复源码修改后启动旧程序的问题；运行脚本按源码内容检查构建结果，缺少识别组件时也会重新构建。
7. 新增完整离线安装包，包含 OCR 组件、模型和所需运行环境，安装时自动检查并补齐，解决单独运行 EXE 提示缺少识别组件的问题。

### 下载与运行

- **推荐下载 ShotInk-Setup.exe**：完整离线安装包，内含主程序、OCR 组件、模型、.NET 8 运行时，以及 .NET Framework 4.8 和 Visual C++ x64 离线安装程序；按提示安装后即可使用，无需另外下载环境。
- **ShotInk-portable.zip**：适合已安装 .NET Framework 4.8 和 Visual C++ x64 运行库的系统。请完整解压后运行其中的 `ShotInk.exe`，保留同目录的 `ocr` 文件夹，勿单独复制 EXE。
- 支持 Windows 10 / 11 x64；若安装提示需要重启，请重启后再运行。
