# ShotInk 轻量便携版

轻量版不包含文字识别引擎、模型、识别按钮或识别功能。截图标注、长截图、贴图缩放、GIF 录制与剪辑、快捷键和软件内更新与完整版共用代码并同步更新。

完整解压后运行 ShotInk.exe，无需安装 .NET SDK。建议解压到独立目录，不与完整版文件混合。

GIF 剪辑的工具栏位于帧计数上方，可用画笔、文字、形状、箭头、马赛克和橡皮擦标注。右侧「当前帧｜选中帧｜全部帧」切换应用范围，默认当前帧。← / → 逐帧查看，红色「删除选中」删除起止范围内的帧，随后手柄复位。

默认录制约 30 帧/秒，可在设置的 GIF 页调整为 1～50 帧/秒。Ctrl+X 删除当前帧，Ctrl+Shift+X 删除选中帧，Ctrl+Z 撤销删除或标注，Ctrl+Y 重做。这三个快捷键可在 GIF 设置中调整。

保存与复制 GIF 使用现有图片保存设置。多帧效果在后台预绘制，导出采用有限并发并保持帧序和原时长。

更新仅在点击「检查更新」时检测，启动和后台均不自动检查，结果在设置显示。轻量版只下载轻量更新包。限流时提示稍后重试，有验证码时才打开软件内验证窗口；校验后点击「确认更新并重启」。配置与截图历史保存在 Windows 用户数据目录，独立于程序目录。

验证窗口使用 Microsoft Edge WebView2 Runtime；缺少运行时时按提示安装后重试。包内保留相应组件及许可证，不包含 docs 或 ocr 文件夹。

## 录屏声音与解压

「设置 → 录屏」可选择麦克风输入设备并调整 100%～400% 的软件增益，默认 200%。录屏前在工具栏开启麦克风，录制结束后自动平衡轻声并限制峰值；剪辑预览和 MP4 使用同一份处理后的录音。麦克风静音或不可用时显示具体原因，未检测到声音时在剪辑窗口提示。

录屏工具栏按选区所在显示器的可用区域定位，靠近屏幕底部时自动移到上方。完整版采用托管组件合并打包以减少解压文件数量，内置更新支持并行解压与同步校验。

## 界面换肤

打开「设置 → 外观」可选择极简线性、双色扁平、柔和立体、磨砂玻璃、暗色霓虹、复古像素、黑白水墨七套皮肤，也可选择经典外观。切换时可直接预览工具栏和按钮，点击「保存」后记住选择，取消或关闭设置会恢复此前皮肤。

皮肤同时覆盖工作台、截图工具栏、标注选项、GIF / 录屏控件和设置窗口。悬停、按下、选中、禁用与截图复制完成提示均采用对应风格，包括细线强调、双色填充、立体按压、玻璃高光、霓虹脉冲、像素位移和灰阶晕墨。标注调色板显示实际绘图颜色。

## 快速截图与窗口识别

- `Ctrl+Alt+Q`：按上次区域的屏幕坐标和尺寸重新截图，自动复制并结束，不打开编辑框。
- `Ctrl+Alt+E`：按上次区域重新截图，直接进入截图工具栏编辑。
- `Ctrl+Alt+A`：截取所有显示器的完整画面，进入编辑。
- `F1` 区域截图时，鼠标悬停自动预选窗口边界，单击直接编辑；长按 350 毫秒或直接拖动进入手动框选。仍可拖动、调整选区或按 Esc / 右键取消。
- 上次区域会随设置保存，重启后继续使用；首次使用快速截图或原区域超出当前屏幕时，提示重新框选。完成全屏截图也会记作上次区域。
- `F3` 优先贴出剪贴板图片；剪贴板没有图片时，贴出截图历史中排在第一位的图片。两处都没有图片时提示先截图。

以上快捷键均可在设置中更改、清除或恢复默认。升级时保留原快捷键，新增默认按键与原绑定冲突时暂不启用，可在设置中另选按键。

确认更新优先于截图和贴图，相关窗口会自动关闭，未保存标注沿用保存确认。更新成功或失败后自动清理安装 ZIP 与解压暂存文件，保留回滚备份和错误日志；版本详情仅供浏览，不支持编辑或选中文字。

快速截图并复制成功后会显示约 1.5 秒的「截图已复制」提示，不抢焦点、不打开编辑器。

### 紧凑选项与选框微调

工具选项以单行图标显示，悬停可查看功能含义，保留精确数值调整。

- 方向键每次移动选框 1 像素；长按任意边框 350 毫秒后，保持鼠标按下，用 ↑↓ 调整上/下边，或 ←→ 调整左/右边。按住方向键连续调整，松开鼠标恢复整体移动。

### 自定义选框

截图时点击顶部的套索图标（或按 L），用画笔圈出要保留的内容。画出有效区域后靠近起点即可吸附并完成；松开鼠标会自动连接未闭合的首尾。选区可继续移动、缩放和方向键微调，标注后保存 PNG 可保留平滑透明边缘。选框模式仅在截图界面上方显示，自动记住上次使用的选项，重启后也会保留。

自定义选框用于静态截图，长截图和 GIF 使用矩形选框；快速截图继续使用上次的矩形区域。

## 录屏

截图选框后，点击 GIF 右侧的摄像机图标，直接复用当前选框，并在选框下方切换为录屏工具栏。可开关麦克风、系统声音和鼠标指针，首次使用会依次显示提示引导。默认开启系统声音和指针，麦克风默认关闭，后续记住上次设置。

点击「开始录屏」，3 秒倒计时结束后开始录制。浮动导航显示有效录制时间，可拖动导航、暂停、继续或结束。每段最多录制 1 分钟，暂停时间自动移除。

结束后进入「编辑录屏」。拖动时间轴两端选中时间段，支持删除选段、删除当前帧、撤销和重做。标注工具可应用于当前帧、选中时间段或全部内容，支持形状、线条、画笔、荧光笔、马赛克、文字与橡皮擦。保存与复制导出当前选段的 MP4，删除片段时同步剪去对应声音。

完整解压便携包并保留 NAudio.dll 和 recording 文件夹。录屏声音使用 Windows 默认输入、输出设备。

### 分段更新

较大的更新包分为两个分段下载，每段分别校验 SHA-256，下载完成后自动合并并校验完整 ZIP，再按正常流程确认更新和重启。轻量版继续支持单包下载，验证窗口支持分段下载过程中的人机验证。

此前尚未支持分段更新的版本，首次需手动下载并完整解压本次新版。安装后即可通过程序内的「检查更新」使用分段更新。
