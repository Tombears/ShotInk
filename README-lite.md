# ShotInk 轻量便携版

轻量版不包含文字识别引擎、模型、识别按钮或识别功能。截图标注、长截图、贴图缩放、GIF 录制与剪辑、快捷键和软件内更新与完整版共用代码并同步更新。

完整解压后运行 ShotInk.exe，无需安装 .NET SDK。建议解压到独立目录，不与完整版文件混合。

GIF 剪辑的工具栏位于帧计数上方，可用画笔、文字、形状、箭头、马赛克和橡皮擦标注。右侧「当前帧｜选中帧｜全部帧」切换应用范围，默认当前帧。← / → 逐帧查看，红色「删除选中」删除起止范围内的帧，随后手柄复位。

保存与复制 GIF 使用现有图片保存设置。多帧效果在后台预绘制，导出采用有限并发并保持帧序和原时长。

更新仅在点击「检查更新」时检测，启动和后台均不自动检查，结果在设置显示。轻量版只下载轻量更新包。限流时提示稍后重试，有验证码时才打开软件内验证窗口；校验后点击「确认更新并重启」。配置与截图历史保存在 Windows 用户数据目录，独立于程序目录。

验证窗口使用 Microsoft Edge WebView2 Runtime；缺少运行时时按提示安装后重试。包内保留相应组件及许可证，不包含 docs 或 ocr 文件夹。

## 快速截图与窗口识别

- `Ctrl+Alt+Q`：按上次区域的屏幕坐标和尺寸重新截图，自动复制并结束，不打开编辑框。
- `Ctrl+Alt+E`：按上次区域重新截图，直接进入截图工具栏编辑。
- `Ctrl+Alt+A`：截取所有显示器的完整画面，进入编辑。
- `F1` 区域截图时，鼠标悬停自动预选窗口边界，单击直接编辑；长按 350 毫秒或直接拖动进入手动框选。仍可拖动、调整选区或按 Esc / 右键取消。
- 上次区域会随设置保存，重启后继续使用；首次使用快速截图或原区域超出当前屏幕时，提示重新框选。完成全屏截图也会记作上次区域。
- `F3` 优先贴出剪贴板图片；剪贴板没有图片时，贴出截图历史中排在第一位的图片。两处都没有图片时提示先截图。

以上快捷键均可在设置中更改、清除或恢复默认。升级时保留原快捷键，新增默认按键与原绑定冲突时暂不启用，可在设置中另选按键。

确认更新优先于截图和贴图，相关窗口会自动关闭，未保存标注沿用保存确认。更新成功或失败后自动清理安装 ZIP 与解压暂存文件，保留回滚备份和错误日志；版本详情仅供浏览，不支持编辑或选中文字。

快速截图并复制成功后会显示约 1.5 秒的「截图已复制」提示，不抢焦点、不打开编辑器。
