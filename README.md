# ShotInk

轻量 Windows 截图工具，支持区域截图、绘图标注、滚动长截图与桌面贴图。下载即可运行，截图保存在本机。

## 下载

前往 [Releases](https://github.com/Tombears/ShotInk/releases/latest) 下载 [完整 OCR 版](https://github.com/Tombears/ShotInk/releases/latest/download/ShotInk-portable.zip) 或 [无 OCR 轻量版](https://github.com/Tombears/ShotInk/releases/latest/download/ShotInk-portable-lite.zip)，完整解压到一个文件夹后运行其中的 `ShotInk.exe`。完整版需保留同目录的 `ocr` 文件夹。两版均提供 ZIP 包。

支持 Windows 10 / 11，需要 .NET Framework 4.8。

## 录屏

截图选框后，点击 GIF 右侧的摄像机图标，重新框选录制区域。选框下方可开关麦克风、系统声音和鼠标指针，首次使用会依次显示气泡引导。默认开启系统声音和指针，麦克风默认关闭，后续记住上次设置。

点击「开始录屏」，3 秒倒计时结束后开始录制。浮动导航显示有效录制时间，可拖动导航、暂停、继续或结束。每段最多录制 1 分钟，暂停时间自动移除。

结束后进入「编辑录屏」。拖动时间轴两端选中时间段，支持删除选段、删除当前帧、撤销和重做。标注工具可应用于当前帧、选中时间段或全部内容，支持形状、线条、画笔、荧光笔、马赛克、文字与橡皮擦。保存与复制导出当前选段的 MP4，删除片段时同步剪去对应声音。

完整解压便携包并保留 NAudio.dll 和 recording 文件夹。录屏声音使用 Windows 默认输入、输出设备。

## 功能

- **区域截图**：`F1` 拖选区域，松开鼠标后保持屏幕选区，并在选区下方显示浮动图标工具栏。支持拖动选区、八个手柄调整大小、跨显示器选区和像素尺寸提示。
- **浮动工具栏**：矩形 / 椭圆、箭头 / 直线、画笔、荧光笔、马赛克、文字、橡皮擦、撤销、重做、取消、贴图、保存、复制。单击工具立即启用默认模式，并展开对应选项；重复单击保持工具启用。
- **独立工具设置**：各工具分别记住颜色和线宽，文字字号、马赛克颗粒、模糊强度与画笔大小、橡皮擦大小互不影响；切换工具、打开新截图和重启后继续保留。
- **文字标注**：选择文字工具后直接在图片上输入，支持中文、多行、独立字号、颜色、粗体和斜体；选中文字后可继续调整样式。拖动边框移动，拖动四角等比缩放，拖动顶部圆点旋转（按住 Shift 按 15° 对齐）；双击或 F2 再次编辑。输入时 Enter 换行、Ctrl+Enter 完成、Esc 取消本次编辑，Ctrl+C 复制输入框中的文字；点击空白处可继续添加文字。移动、缩放、旋转及文字修改均可撤销、重做，导出只保留文字。
- **马赛克与橡皮擦**：均支持「画笔 / 选框」，默认使用画笔。马赛克像素块根据原图颜色取均值，自适应背景明暗并保留彩色内容；也可选择高斯模糊，分别设置颗粒大小、模糊强度，并保留独立的画笔直径。方块连续覆盖，缩放时不出现白色细缝。选框马赛克带虚线编辑框，可继续移动、缩放和切换效果，编辑框不进入导出；橡皮擦按涂抹或框选范围恢复原图。每次操作支持撤销和重做。
- **点按线条**：在线条选项中选择「直线」或「箭头」，第一次单击确定起点，后续单击添加折点；右键、双击或 Enter 完成，Backspace 退回一个节点，Esc 取消当前线条。两点组成直线，多点组成折线，箭头只显示在最后一段末端。整条线可一次撤销和重做。
- **图片选字**：点击橡皮擦右侧的「方框＋文」，识别完成后自动全选，以连续荧光色带高亮，不再逐字显示小格；可继续拖选文字或跨行选择表格的一列。支持中英文、数字和标点，单击选择英文词、双击选择整行、`Ctrl+A` 全选、`Ctrl+C` 复制选中文字。高亮不进入导出图片，点击绘图工具或 `Esc` 返回标注。
- **滑条手柄**：椭圆形手柄带渐变高光和阴影，支持拖动、点击轨道、方向键及滚轮调整。
- **标注导出**：直接在选区上绘制，`Enter` / 双击未选择绘图工具的选区 / `Ctrl+C` 复制并结束，`Ctrl+S` 保存 PNG；工具栏、边框和手柄均不进入导出图片。长图在固定选框内滚动浏览并导出整图，历史图片使用可缩放编辑器。
- **桌面贴图**：`F3` 将剪贴板图片置顶。拖动位置，滚轮缩放，右键切换半透明，双击或 `Esc` 关闭。
- **滚动长截图**：先截图框选，再点文字识别右侧的长截图图标；直接使用当前选区。手动滚动原窗口，后台检测变化并异步拼接；采集时仅显示「完成」。结束后恢复完整工具栏，长图以原像素在固定框内显示，用滚轮或滚动条浏览；选择「移动选区」后可拖动整个长截图框，继续标注、识别、复制与保存。
- **本地历史**：默认保留最近 10 张截图，可在工作台「保留历史」旁直接修改张数或关闭历史记录；双击历史图片继续编辑。手动保存目录与历史记录独立。
- **托盘常驻**：关闭工作台后仍可使用全局快捷键，从托盘菜单退出。
- **设置**：从工作台左侧或托盘菜单打开「设置」，可修改截图、剪贴板贴图、长截图快捷入口的全局快捷键，以及图片默认保存文件夹和「每次保存时询问保存位置」开关。关闭询问后，保存按钮和 `Ctrl+S` 直接保存到指定文件夹；快捷键冲突会提示并保留原绑定。支持「开机启动」，默认关闭；开启并保存后，登录 Windows 时自动启动并驻留托盘，双击托盘图标可打开工作台，取消勾选并保存即可关闭。移动程序文件夹后，请重新打开设置并保存以更新启动路径。修改历史保留张数不会清理手动保存的图片。
- **版本下载**：GitHub Releases 提供中文版本说明和完整 ZIP 包。
- **应用图标**：采用彩色四角截图框与黄色钢笔的最终稿，程序文件、托盘和编辑窗口保持一致。

## 运行

ZIP 包支持 Windows 10 / 11 x64，包含主程序、OCR 组件、模型和 OCR 自带的 .NET 8 运行时；无需安装 Python、.NET SDK 或额外下载模型。系统需要已有 .NET Framework 4.8 和 Visual C++ x64 运行库。首次使用 OCR 会加载模型，之后复用同一进程；截图全程在本地处理。

双击 `dist\ShotInk.exe`。也可以在项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
```

运行脚本会检查源码内容；首次运行或源码变化后自动重新编译。更新源码后请先从系统托盘退出正在运行的程序，再运行脚本，避免继续使用旧 EXE。工作台标题会显示当前程序版本。源码构建还需要 **.NET SDK 8 或更新版本**，首次构建需联网还原锁定的 NuGet 依赖并下载校验模型：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

默认同时构建两版：完整版位于 `dist\`，交付 `ShotInk-portable.zip`；轻量版位于 `dist-lite\`，交付 `ShotInk-portable-lite.zip`。Visual Studio 也可打开 `ShotInk.csproj`（需要 .NET Framework 4.8 targeting pack）。主程序保持 .NET Framework 4.8。

OCR 使用 [RapidOcrNet](https://github.com/BobLd/RapidOcrNet) + ONNX Runtime 的 PP-OCRv6 small 模型，输出限定为中英文、数字和标点；关闭方向分类推理，复用模型会话并缓存上一张图片的结果。项目比较、实测和已知限制见 [OCR 技术说明](https://github.com/Tombears/ShotInk/blob/main/docs/ocr.md)。

## 普通截图操作

普通截图选区后即可使用浮动工具栏。未选择绘图工具时可拖动整个选区；点击工具栏最左侧的「移动选区」图标可回到拖动模式。单击形状或线条立即使用默认工具，并在下方切换矩形 / 椭圆或箭头 / 直线。线条用单击逐点连接，右键或双击完成。

单击马赛克或橡皮擦即可涂抹，在下方选择「选框」可拖动框选区域；选框模式下画笔大小滑条会禁用，马赛克颗粒大小或模糊强度仍可调节。马赛克框选后，可拖动虚线框内部移动效果范围，拖动八个小方块改变大小，点击空白处继续新建；修改效果和范围均可撤销。截图选区的蓝色手柄用于调整截图边界；点击选区外可重新框选，`Esc` 或右键取消。

快捷键占用状态显示在设置的按键输入框旁，每秒自动刷新；修改按键后立即重新检测。占用解除后显示「未占用」。设置打开期间暂停全局快捷键；关闭设置后，程序每秒重试注册失败的按键，其他程序释放按键后自动恢复，无需重启。未设置、无效按键和本页重复的按键会分别提示；保存时仍会检查能否注册。

更新程序时先从托盘退出，再替换完整便携包内容。设置保存在当前 Windows 用户的数据目录，与程序安装目录分开；更新会继续使用已有配置，空的新目录不会遮蔽旧配置。保存设置时保留上次备份；主配置缺失或损坏时尝试恢复，读取失败会提示并暂停保存，避免默认值覆盖原设置。

桌面贴图可拖动四边或四角等比例缩放；鼠标靠近边缘时自动切换横向、纵向或对角线缩放光标，并高亮可拖动的边缘。拖动图片中央可移动贴图，滚轮可缩放，右键「原始大小」恢复原尺寸；复制保留原图像素。

## 版本更新

更新仅在点击「检查更新」时检测，启动和后台均不自动检查。检测结果显示在设置中，不自动弹窗或显示托盘气泡。从工作台、设置或托盘菜单点击「检查更新」会立即重新检测。发现更新后，点击「查看并更新」查看说明，再点击「下载更新」；校验完成后点击「确认更新并重启」，程序会备份并替换文件后重新启动，保留保存目录、快捷键、工具参数和截图历史。同版本修复包也能识别，已安装相同构建时不重复更新，不降级安装旧版本。

点击「确认更新并重启」后，会自动结束截图、关闭贴图和编辑窗口；标注编辑器有未保存修改时会提示保存，取消关闭会明确提示更新已取消。从设置窗口更新时会先保存当前设置。设置保存失败或安装目录没有写入权限时不会关闭程序。下载缓存优先放在 E 盘，更新目录保留安装备份；复制失败时尝试恢复原文件。遇到请求限流时提示稍后重试，有验证码时才打开软件内验证窗口。

首次使用本功能需完整解压新版便携包，保留 `ShotInk.build.sha256`、`update-portable.ps1` 和 WebView2 组件。检查和下载更新均在软件内完成，无需提供账号或令牌。

更新服务要求人机验证时，下载流程会弹出内嵌验证窗口，由你完成验证后继续在同一浏览器会话中下载，再校验更新包。版本查询需要验证时，设置中显示「完成验证」入口，点击后才打开验证页面；关闭验证窗口可取消，程序继续运行。验证完成后若页面没有自动继续，可点击「已完成验证，继续」。

验证窗口需要 Microsoft Edge WebView2 Runtime；未安装时会显示原因，可从[微软官网下载](https://developer.microsoft.com/microsoft-edge/webview2/)安装后重试。验证失败时可关闭窗口，稍后重新检查或下载更新。

## 两种便携版

- ShotInk-portable.zip：完整 OCR 版，含本地文字识别引擎和模型。
- ShotInk-portable-lite.zip：轻量版，编译移除文字识别功能和按钮，不包含 OCR 组件。

两版通用功能共用代码并同步构建、测试和发布，各自只接收对应版本的更新包；请分别解压到独立目录。两个新便携包均不包含 docs 文件夹，历史版本附件保留。

## GIF 录制与剪辑

框选区域后，点击长截图右侧的 GIF 播放方框图标开始录制。点击「停止录制」打开剪辑窗口，在同一条时间轴上拖动起点、终点双滑块选择要保留的区段。预览区按 ← / → 逐帧查看；选中起点或终点滑块后按 ← / →，每次调整一帧。时间轴聚焦时可用 Home / End 选择起点或终点手柄。支持播放所选区段、复制 GIF（Ctrl+C）与保存 GIF（Ctrl+S）；保存沿用图片默认目录和保存询问设置。复制保留动画文件，需目标应用支持 GIF 文件粘贴。

GIF 帧计数上方的工具栏支持形状、线条、画笔、荧光笔、文字、马赛克、橡皮擦和撤销重做。右侧分段按钮「当前帧｜选中帧｜全部帧」默认高亮当前帧，按范围同步新绘制的效果，保持每帧自己的画面；完整版文字识别固定只处理当前帧。GIF 工具栏不显示长截图和录制入口。

多帧效果采用后台有限并发预绘制，缓存上限 64 MiB；GIF 编码并行处理小批次帧，再按原帧顺序和时长组装。两版均使用相同实现。

点击红色文字「删除选中」会删除当前起点至终点之间的全部帧（包含两端），接合剩余内容并保留其播放时长；起止手柄随后复位到剩余内容的首尾，可继续逐帧调整、删除、复制和保存。删除全部帧后显示空白预览，停止播放并禁用导出。

默认约 30 帧/秒，可在设置中调整默认每秒帧数（1～50）。实际采样间隔取决于画面大小和编码耗时，导出保留实际时长。单次录制最多 60 秒或 192 MiB 压缩帧缓存，达到上限后保留内容并进入剪辑。Esc 取消录制。录制原始屏幕内容，不包含截图标注。

「删除当前帧」（Ctrl+X）删除正在查看的一帧；「删除选中」（Ctrl+Shift+X）删除起止范围内的帧。Ctrl+Z 撤销最近的删除或标注，Ctrl+Y 重做，连续撤销可恢复帧画面、时长和选区。默认每秒帧数和这三个快捷键可在设置的 GIF 页调整。

滑块使用与功能对应的颜色，右侧数值框可点击输入实际数值。GIF 起点与终点数值框分别位于滑轨左上角、右上角，按帧序号输入；回车或离开输入框时自动限制有效范围。

截图工具栏采用紧凑圆角外观，拖动最左侧点阵握柄即可移开工具栏；切换绘图工具后保留拖动位置。

## 长截图操作

1. 打开目标网页或文档，等待内容加载完成，停在需要截图的起点。
2. 按 `F1` 框选内容范围，避开固定页头、页脚和侧栏，再点文字识别右侧的长截图图标。`Ctrl+Alt+L` 也可直接框选并开始同一流程。
3. 工具栏只保留「完成」，手动向上或向下滚动原窗口；鼠标在选框内或停留在工具栏上均可使用滚轮。上一帧处理完成后及时响应后续滚轮；改变滚动方向时优先执行新方向，不再继续积压的旧方向滚动。从页面中间开始，也能向上补齐顶部、向下继续采集；经过已采集区域不会重复添加。程序以 10ms 为目标间隔检测变化，后台异步拼接；实际频率受系统调度与截图耗时影响。
4. 点击「完成」，原选框变为固定大小的长图预览，工具栏恢复。预览保持原像素大小，不再为了给滚动条留空间而缩小文字；用滚轮或右侧滚动条上下浏览，底部滚动条查看右侧边缘。选择工具栏最左侧的「移动选区」后，按住图片即可拖动整个长截图框；移动时统一绘制预览并擦除旧位置，保留图片内容、标注和滚动位置。导出包含整张长图。

高度达到 30,000 像素或总像素达到 8,000 万时自动完成并保留已拼接部分。长图可向上下两端扩展。鼠标移动、移出选框或悬停引起的页面变化不会自动结束采集。拖动页面滚动条造成的大跨度跳转、动画和固定覆盖内容可能影响匹配；失配时保留已拼接内容，可回滚页面恢复重叠后继续，或点击「完成」保留可拼接部分，预览中会提示未恢复的失配。按 `Esc` 取消本次截图。

长截图完成后点击「文字识别」，会按 CPU 数量最多两路并行识别整张长图，保留完整坐标和阅读顺序。识别后右上角显示搜索框，输入中英文关键词即可查看匹配数量并自动滚动到结果；搜索兼容空格、全角字符及同一行的拆分文字块，例如 `list` 也能查找 `L i s t`，复制内容保持原样。`Ctrl+F` 聚焦搜索，`Enter` / `F3` 查找下一处，`Shift+Enter` / `Shift+F3` 查找上一处；搜索框内按 `Esc` 关闭搜索，仍可继续选择、复制文字。历史图片编辑器也支持搜索；搜索高亮不进入导出图片。

| 保存编辑结果 | `Ctrl+S` |
| 复制编辑结果 | `Ctrl+C` |
| 撤销最近标注 | `Ctrl+Z` |
| 重做最近撤销 | `Ctrl+Y` |
| 完成区域截图并复制 | `Enter` |

以上为默认快捷键，可在「设置」中更改。若快捷键被其他程序占用，可更换组合，或使用工作台按钮和托盘菜单。

设置窗口打开期间暂停截图、长截图和贴图快捷键，同时禁用截图入口；可直接录入原先已绑定的按键。关闭设置后恢复快捷键，保存使用新设置，取消则继续使用原设置。

截图和设置目录：`%LOCALAPPDATA%\ShotInk`。从旧版升级时，如果存在 `%LOCALAPPDATA%\SnipasteLite` 且尚无新目录，会继续使用旧目录，保留截图历史与设置。应用本身不会向网络上传截图；GitHub 上传脚本只上传本项目源码，构建产物和运行数据均不纳入 Git。

## 快速截图与窗口识别

- `Ctrl+Alt+Q`：按上次区域的屏幕坐标和尺寸重新截图，自动复制并结束，不打开编辑框。
- `Ctrl+Alt+E`：按上次区域重新截图，直接进入截图工具栏编辑。
- `Ctrl+Alt+A`：截取所有显示器的完整画面，进入编辑。
- `F1` 区域截图时，鼠标悬停自动预选窗口边界，单击直接编辑；长按 350 毫秒或直接拖动进入手动框选。仍可拖动、调整选区或按 Esc / 右键取消。
- 上次区域会随设置保存，重启后继续使用；首次使用快速截图或原区域超出当前屏幕时，提示重新框选。完成全屏截图也会记作上次区域。
- `F3` 优先贴出剪贴板图片；剪贴板没有图片时，贴出截图历史中排在第一位的图片。两处都没有图片时提示先截图。

以上快捷键均可在设置中更改、清除或恢复默认。升级时保留原快捷键，新增默认按键与原绑定冲突时暂不启用，可在设置中另选按键。

确认更新优先于截图和贴图，相关窗口会自动关闭，未保存标注沿用保存确认。更新成功或失败后自动清理安装 ZIP 与解压暂存文件，保留回滚备份和错误日志；版本详情仅供浏览，不支持编辑或选中文字。

快速截图并复制成功后会显示约 1.5 秒的「截图已复制」提示，不抢焦点、不打开编辑器。

### 紧凑选项与选框微调

工具选项以单行图标显示，悬停可查看功能含义，保留精确数值调整。

- 方向键每次移动选框 1 像素；长按任意边框 350 毫秒后，保持鼠标按下，用 ↑↓ 调整上/下边，或 ←→ 调整左/右边。按住方向键连续调整，松开鼠标恢复整体移动。

### 自定义选框

截图时点击顶部的套索图标（或按 L），用画笔圈出要保留的内容。画出有效区域后靠近起点即可吸附并完成；松开鼠标会自动连接未闭合的首尾。选区可继续移动、缩放和方向键微调，标注后保存 PNG 可保留平滑透明边缘。选框模式仅在截图界面上方显示，自动记住上次使用的选项，重启后也会保留。

自定义选框用于静态截图，长截图和 GIF 使用矩形选框；快速截图继续使用上次的矩形区域。
