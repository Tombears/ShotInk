# ShotInk

轻量 Windows 截图工具，支持区域截图、绘图标注、滚动长截图与桌面贴图。下载即可运行，截图保存在本机。

## 下载

前往 [Releases](https://github.com/Tombears/ShotInk/releases/latest) 下载 [ShotInk-portable.zip](https://github.com/Tombears/ShotInk/releases/latest/download/ShotInk-portable.zip)，完整解压到一个文件夹后运行其中的 `ShotInk.exe`，保留同目录的 `ocr` 文件夹。后续版本统一提供 ZIP 包。

支持 Windows 10 / 11，需要 .NET Framework 4.8。

## 功能

- **区域截图**：`F1` 拖选区域，松开鼠标后保持屏幕选区，并在选区下方显示浮动图标工具栏。支持拖动选区、八个手柄调整大小、跨显示器选区和像素尺寸提示。
- **浮动工具栏**：矩形 / 椭圆、箭头 / 直线、画笔、荧光笔、马赛克、文字、橡皮擦、撤销、重做、取消、贴图、保存、复制。单击工具立即启用默认模式，并展开对应选项；重复单击保持工具启用。
- **独立工具设置**：各工具分别记住颜色和线宽，文字字号、马赛克颗粒与画笔大小、橡皮擦大小互不影响；切换工具、打开新截图和重启后继续保留。
- **文字标注**：选择文字工具后直接在图片上输入，支持中文、多行、独立字号、颜色、粗体和斜体；选中文字后可继续调整样式。拖动边框移动，拖动四角等比缩放，拖动顶部圆点旋转（按住 Shift 按 15° 对齐）；双击或 F2 再次编辑。输入时 Enter 换行、Ctrl+Enter 完成、Esc 取消本次编辑，Ctrl+C 复制输入框中的文字；点击空白处可继续添加文字。移动、缩放、旋转及文字修改均可撤销、重做，导出只保留文字。
- **马赛克与橡皮擦**：均支持「画笔 / 选框」，默认使用画笔。马赛克的第一条滑条控制颗粒大小，第二条控制画笔直径；橡皮擦提供独立的画笔大小滑条，按涂抹或框选范围恢复原图。每次操作支持整体撤销和重做；历史图片和长截图编辑器也提供相同选项。
- **图片选字**：点击橡皮擦右侧的「方框＋文」，识别完成后自动全选，以连续荧光色带高亮，不再逐字显示小格；可继续拖选文字或跨行选择表格的一列。支持中英文、数字和标点，单击选择英文词、双击选择整行、`Ctrl+A` 全选、`Ctrl+C` 复制选中文字。高亮不进入导出图片，点击绘图工具或 `Esc` 返回标注。
- **滑条手柄**：椭圆形手柄带渐变高光和阴影，支持拖动、点击轨道、方向键及滚轮调整。
- **标注导出**：直接在选区上绘制，`Enter` / 双击未选择绘图工具的选区 / `Ctrl+C` 复制并结束，`Ctrl+S` 保存 PNG；工具栏、边框和手柄均不进入导出图片。长图和历史图片继续使用可缩放编辑器。
- **桌面贴图**：`F3` 将剪贴板图片置顶。拖动位置，滚轮缩放，右键切换半透明，双击或 `Esc` 关闭。
- **滚动长截图**：`Ctrl+Alt+L` 选择内容区域，支持自动滚动和手动滚动后逐屏采集，匹配重叠区域后拼接。
- **本地历史**：默认保存最近 100 张截图，可关闭自动保存；普通截图完成时保存带标注的结果，长截图保存原始长图，双击历史图片继续编辑。
- **托盘常驻**：关闭工作台后仍可使用全局快捷键，从托盘菜单退出。
- **设置**：从工作台左侧或托盘菜单打开「设置」，可修改区域截图、剪贴板贴图、滚动长截图的全局快捷键，以及图片默认保存文件夹和「每次保存时询问保存位置」开关。关闭询问后，保存按钮和 `Ctrl+S` 直接保存到指定文件夹；快捷键冲突会提示并保留原绑定。历史记录仍单独保留最近 100 张，不会清理手动保存的图片。
- **版本下载**：GitHub Releases 提供中文版本说明和完整 ZIP 包。

## 运行

ZIP 包支持 Windows 10 / 11 x64，包含主程序、OCR 组件、模型和 OCR 自带的 .NET 8 运行时；无需安装 Python、.NET SDK 或额外下载模型。系统需要已有 .NET Framework 4.8 和 Visual C++ x64 运行库。首次使用 OCR 会加载模型，之后复用同一进程；截图全程在本地处理。

双击 `dist\ShotInk.exe`。也可以在项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
```

运行脚本会检查源码内容；首次运行或源码变化后自动重新编译。更新源码后请先从系统托盘退出正在运行的程序，再运行脚本，避免继续使用旧 EXE。工作台标题会显示当前程序版本。源码构建还需要 **.NET SDK 8 或更新版本**，首次构建需联网还原锁定的 NuGet 依赖并下载校验模型：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

构建目录包含 `dist\ShotInk.exe` 和 `dist\ocr\`，交付文件为 `ShotInk-portable.zip`。Visual Studio 也可打开 `ShotInk.csproj`（需要 .NET Framework 4.8 targeting pack）。主程序保持 .NET Framework 4.8。

OCR 使用 [RapidOcrNet](https://github.com/BobLd/RapidOcrNet) + ONNX Runtime 的 PP-OCRv6 small 模型，输出限定为中英文、数字和标点；关闭方向分类推理，复用模型会话并缓存上一张图片的结果。项目比较、实测和已知限制见 [OCR 技术说明](docs/ocr.md)。

## 普通截图操作

普通截图选区后即可使用浮动工具栏。未选择绘图工具时可拖动整个选区；点击工具栏最左侧的「移动选区」图标可回到拖动模式。单击形状或线条立即使用默认工具，并在下方切换矩形 / 椭圆或箭头 / 直线。

单击马赛克或橡皮擦即可涂抹，在下方选择「选框」可拖动框选区域；选框模式下画笔大小滑条会禁用，马赛克颗粒大小仍可调节。八个手柄随时可用于调整截图边界；点击选区外可重新框选，`Esc` 或右键取消。

## 长截图操作

1. 打开目标网页或文档，等待图片、字体加载完成，滚动到想截图的起点。
2. 按 `Ctrl+Alt+L`，拖选**可以滚动的内容区域**，避开浏览器标签栏、固定页头、固定底栏和侧边栏。
3. 选择自动滚动，点击「开始」。工具以选区中心为滚动目标，每次滚动后等待指定毫秒数再采集；连续三次画面未变化时自动完成。
4. 动画、懒加载或特殊滚动控件可使用手动模式：点击「开始」采集首屏，自己向下滚动少量，再点击「采集一屏」。相邻画面保留至少约 20% 的重叠；推荐每次滚动不超过半屏。
5. 点击「完成」进入编辑器，复制或保存长图。取消则丢弃本次采集。

匹配不可靠时会暂停并保留已拼接部分；返回上一位置后可在手动模式重试。自动模式暂停后可直接完成，重新发起截图可更换模式。超过 30,000 像素高或 8,000 万总像素时停止追加。只支持向下的垂直滚动；整屏无纹理、视频、动态布局、受保护窗口和固定覆盖内容可能无法正确拼接。不同滚动控件对系统滚轮响应不同，可改用手动模式。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 区域截图 | `F1` |
| 剪贴板贴图 | `F3` |
| 长截图 | `Ctrl+Alt+L` |
| 保存编辑结果 | `Ctrl+S` |
| 复制编辑结果 | `Ctrl+C` |
| 撤销最近标注 | `Ctrl+Z` |
| 重做最近撤销 | `Ctrl+Y` |
| 完成区域截图并复制 | `Enter` |

以上为默认快捷键，可在「设置」中更改。若快捷键被其他程序占用，可更换组合，或使用工作台按钮和托盘菜单。

截图和设置目录：`%LOCALAPPDATA%\ShotInk`。从旧版升级时，如果存在 `%LOCALAPPDATA%\SnipasteLite` 且尚无新目录，会继续使用旧目录，保留截图历史与设置。应用本身不会向网络上传截图；GitHub 上传脚本只上传本项目源码，构建产物和运行数据均不纳入 Git。
